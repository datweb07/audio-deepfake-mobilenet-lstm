# Phase 5 preprocessing mechanism

For nonzero scalar a, linear STFT gives S(ax)=aS(x). A fixed nonnegative linear Mel projection of squared magnitude gives P(ax)=a²P(x), up to numerical rounding, resampling, clipping and boundary behavior. This argument presumes the same segment boundaries and no gain-dependent waveform clipping or normalization.

P0 uses absolute floor ε=1e-10. The normalized dB response is approximately `10 log10(max(P, ε)) − max[10 log10(max(P, ε))]`, with dynamic-range clipping. In general `max(a²P, ε) != a² max(P, ε)`. A bin crossing the absolute floor changes its relative dB value, even if the waveform is only attenuated. Scaling ε by a² in a counterfactual explains the earlier numerical mechanism, but would require the unobserved original gain and is not the deployed candidate.

P1 instead sets R=max(P) per segment and computes `max(10 log10(max(P/R, 1e-8)), −80)`, mapped to 0–255 and resized exactly to the production temporal-image dimensions. For R>0, `(a²P)/(a²R)=P/R`: the ideal representation is invariant without knowing original amplitude. The implementation performs float64 power/reference arithmetic after float32 waveform/STFT preparation. Exact algebraic invariance does not ensure bitwise numerical invariance for arbitrary gain, and neither ensures useful classification. Half gain is a binary scaling with especially favorable floating-point behavior.

P1 silence R=0 is explicitly −80 dB / zero pixels. P0 silence maps differently (constant high pixels after its relative-reference policy). This is a distribution change and a failure control, not a claim that all observed effects arise solely from one floor parameter. P1 also changes numerical precision and reference semantics; a future mechanism ablation must separate these details.

P2 is a conventional observed 3-second-window RMS target .1 followed by unmodified P0. It uses no reference original waveform. Zero RMS stays zero. It can amplify weak noise, changes absolute amplitude cues and has no clipping step; it is a normalization baseline rather than a new floor algorithm. P3 means amplitude augmentation during **training**, implemented as B1; it is not an inference preprocessing policy and is not equivalent to P2.

The actual P0/P1/P2 diagnostic holds IDs, old checkpoint bytes and thresholds fixed on 32 MLAAD development recordings. 384 forwards include 128 P0 bridge/embedding calls (parity against sealed Phase 4 scores) and 256 new P1/P2 diagnostic calls. LSTM embeddings were observed without changing weights. P1/P2 give zero half-gain feature/embedding/score residuals on this cohort. P0 gives 3 MobileNet and 2 ShuffleNet decision flips. P1 improves MobileNet native error from .25 to .125 but worsens ShuffleNet from .1875 to .3125. This supports a preprocessing contribution to gain instability but does not establish exclusive causation, preserved forensic cues or trained-model superiority.

The deployed production function is unchanged. Fingerprinted policies reside in src/lava/jaes_v2/preprocessing.py. [librosa power-to-dB documentation/source](https://librosa.org/doc/main/_modules/librosa/core/spectrum.html) demonstrates that reference normalization and flooring are established operations; their use alone is not novelty. Executed CSVs, paired embedding/score differences and checkpoint hashes reside in outputs/jaes_v2/phase5_preprocessing_study_v1/.
