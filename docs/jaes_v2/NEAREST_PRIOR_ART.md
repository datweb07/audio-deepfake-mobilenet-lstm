# Nearest prior art and access depth

Primary-source review on 24–25 October 2026. Reading depth is stated explicitly; unavailable full texts are not represented as fully reviewed.

1. **PCL-NET / Exposing and Mitigating Neural Codec Vulnerabilities** (2026 preprint). Methodology §IV inspected: shared XLS-R frontend, layer fusion, L1 consistency between original/codec representations and supervised labels on both views; inference is single-view. This overlaps the naive C2 proposal. No new claim is made for those components. [Full text](https://arxiv.org/html/2610.07216v1).
2. **Neural Audio Codec for Robust Audio Deepfake Detection / FP-NAC** (2026 preprint). §§3–5 inspected: mixed clean/coded class trials separate asymmetric codec effects; the intervention adapts the codec with detector guidance. C1 must exceed class-wise diagnostics, and C2 must not confuse detector training with codec adaptation. The linked official repository currently exposes README/license only, so implementation availability was not assumed. [Paper](https://arxiv.org/html/2609.39651v1), [repository](https://github.com/kjungwoo03/FP-NAC).
3. **DK-CAST** (2025 journal article). §§3.2–3.6 and availability inspected: teacher/student transfer, quality streams, adaptive fusion, multiple distillation terms and codec-related modulation. Code is on request. An independently reproduced baseline must disclose missing details; it cannot be called an official implementation. [Publisher](https://link.springer.com/article/10.1007/s10791-025-09746-4).
4. **CodecFake+** (arXiv v3, revised June 2026). Dataset/taxonomy sections inspected; distinguishes resynthesized proxy speech from codec-based generation. Its earlier v1 title differs. The supplied IEEE DOI was not independently resolved; do not certify publication metadata from that DOI alone. [Versioned text](https://arxiv.org/html/2501.08238v3).
5. **Robustness survey and experimental case study** (online 2026). Publisher record and author-repository full text retrieved. Dataset bias, codec masking and artifact overfitting already frame the problem. Detailed experimental reconstruction is still pending. [Publisher](https://doi.org/10.1016/j.csl.2026.102037), [author repository](https://repository.uwl.ac.uk/id/eprint/15273/).
6. **Noise-masked attacks, DSPA 2026**. Publisher abstract verified; full text unavailable through the tool. Clean-selected fixed thresholds and class asymmetry are already reported, so neither is a standalone new metric claim. [IEEE record](https://ieeexplore.ieee.org/abstract/document/11476736).
7. **RADAR 2026** preprint. Dataset and media-transformation sections inspected: sequential transformations and unseen distribution conditions are already part of an audio-deepfake benchmark. Independent A→B/B→A estimates may be a useful study design, but novelty is unverified. [Full text](https://arxiv.org/html/2605.09568v1).
8. **Adaptive Compression and Targeted Perturbation** (October 2026 preprint). Methodology inspected: input-conditioned feature routing and frequency-targeted training create additional overlap risk for C2/C3; this is not itself selective abstention. [Full text](https://arxiv.org/html/2610.16049v1).

Additional relevant sources are catalogued in LITERATURE_MATRIX.csv with limited reading levels rather than inflated “fully read” labels. No nearest audio-specific budgeted abstention paper has yet been exhaustively excluded; C3's novelty gate remains open.
