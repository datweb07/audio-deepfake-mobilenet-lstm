## Candidate protocol, pending qualification

Prefer a provenance-screened In-the-Wild subset over full DF acquisition if an external diagnostic is required. Lock the exact archive identity and metadata hash first. From official rows, choose 16 speakers with adequate support in both classes. Select 16 unique REAL and 16 unique FAKE originals per speaker with a deterministic source order keyed by seed 20261112. Require unique recording/source groups and exclude known overlapping source IDs, speaker aliases and duplicate audio against train, development, calibration and prior held-out. Record attack coverage and parent relations when supported. If these fields cannot resolve overlap, report a distribution-shift diagnostic or defer independent confirmation. Selection has not been executed because audio rights, parent/video lineage and group support remain unverified. No source list or selected-row hash has been approved. Do not replace failed quotas with unchecked records.

Predefine all six frozen selected checkpoints in the [three-seed review](THREE_SEED_REPLICATION_REVIEW.md), a single native input per recording, unchanged P0 inference, FAKE score orientation and threshold 0.5. At 512 sources this is 3,072 predictions. At the measured clean CPU latency of about 102 ms per input, forward plus baseline preprocessing scale is about 5.2 minutes before remote I/O, decode checks, model loads and verification. Exact WAV formats/sample rates, decoder compatibility, metadata-to-member identity, audio SHA-256 and selected-row hash must be verified before scoring. Report AUC, REAL false-alarm and FAKE miss separately, with speaker-cluster uncertainty and no threshold fitting. Adding new channel conditions would be a different protocol.

No approved data-lock or scoring CLI exists for this candidate. The original locked held-out runner is for ASVspoof 2019 and is not a substitute. Obtain author approval after the independent subset, rights and exact execution contract are qualified. For the December manuscript, retain the cross-corpus limitation. If only one follow-up is possible, the bounded size diagnostic is more directly aligned with the current intervention and RQ1/RQ2. An independent corpus would add broader external validity and requires greater provenance work.

Direct ZIP access or bounded range retrieval is compatible with the measured disk budget in principle. The previous 512-source, six-checkpoint estimate remains about 5.2 minutes of measured-scale CPU preprocessing and forward work before I/O and verification. R08 evaluates frozen models and requires no training.

Available storage does not establish independent evaluation. WAV member presence and label support were verified at metadata level. Actual decode, duplicates, aliases, source grouping and the underlying audio-use terms still require evidence. A bounded diagnostic of distribution shift could proceed after audio-use rights, exact bytes, decode, label reconciliation, available overlap checks and a prospective evaluation lock are established. It would explicitly report residual lineage uncertainty. Independent confirmation requires defensible source and speaker disjointness. The original 2019 LA held-out evaluation remains within-release.
