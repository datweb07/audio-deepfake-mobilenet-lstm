# Phase 5 bounded CPU resource plan

Physical inventory is 12 logical CPUs and RTX 3050 Laptop 4 GiB. Installed TensorFlow 2.15 on Windows is CPU-only; existing Torch 2.2.2 is also CPU-only. No CUDA acceleration is assumed and no production dependency changes were made. CPU TensorFlow intra/inter-op threads are fixed to one.

Resource V1 used a cold encoder projection and returned AWAITING_COMPUTE (~810 s versus 600 s cache allowance). It is preserved. Resource V2 measures five batch-two encoder passes and an actual train-audio decode plus both preprocessors: warm batch-two encoder .37556 s, actual decode/two-policy preprocessing .07997 s, projected cache 508.16 s. Synthetic full forward batch two .62216 s; backward + Adam .39855 s; gradient norm 5.27139; input tensor 7,225,344 bytes; sampled RSS 1,086.02 MiB; OS lifetime peak 1,147.29 MiB; no GPU; 1,308,401 parameters; serialized preflight model 5,916,718 bytes. These are resource fixtures, not detection results.

Projection is an estimate, not a guaranteed upper bound despite the historical JSON field name. Actual wall-clock gates take precedence. Feature extraction now pairs P0/P1 in a batch-two call, matching the resource probe. Any incomplete or over-budget cache is FAILED_OR_INTERRUPTED and cannot train. Existing failed directories are never overwritten; the exact completed cache path is pinned in every resolved training config.

Tier 0: finite shape/loss, nonzero gradients, scratch active-backbone policy, native Keras save/reload, interruption and leakage tests. Tier 1: 16 legitimate ASV train records (8/8), overfit accuracy >=.9375, at most 100 epochs and 180 seconds; development scores from this run are diagnostic only. Tier 2 is gated on Tier 1 and consists of four seed-5804 P0/P1×B0/B2 cells, 6 fixed epochs, batch16, Adam .001, identical linear decay and updates, at most 180 seconds each. Only a pretrained frozen ImageNet backbone plus fresh LSTM/Dense head is trained. This is not end-to-end finetuning. Cached embeddings are mathematically appropriate for this deterministic frozen feature extractor, not for a trainable backbone.

Each run records actual seconds, OS process peak working set, model bytes and optimizer steps. Peak memory is OS lifetime peak, not GPU VRAM or a sampled-RSS substitute. A separate small full-student cost study measures decode/headroom, preprocessing, model-only, end-to-end and offline RTF; no streaming/energy claim follows.

Keep 15 GiB free. No multi-hour training, teacher install, multiseed or external corpus download is automatically started. Phase 6 should select a compatible isolated Linux/WSL GPU or external runtime and reproduce existing architecture/score contracts before full finetuning. Hardware name alone does not validate VRAM fit. Tier 3 requires a locked protocol, baseline validation, finalized method and explicit compute budget; at least three independent training seeds then become mandatory.
