# Phase 4 matched cohort protocol

**SOURCE_MATCHED_EXPERIMENT_BLOCKED.** No fake `phase4_source_matched_dev_v1.json` or matched-source inference run was created.

`matched_analysis.select_matched` requires two explicit system IDs, at least level-3 author source evidence, complete source×system cells, one common language, unambiguous single rendition per cell, a minimum eight common original recordings and five original source-text speakers. Selection is seeded and speaker-balanced, retains equal source contribution across systems and accepts no scores. Missing/weak/ambiguous support returns a named status or fails. Source matching strength is separate from proof of statistical independence.

`matched_interaction` implements the source-level contrast `[(AB−BA)first − (AB−BA)second]`, with matched content only across documented identical source IDs, paired same-record views within each system, then equal original-speaker cluster weight. It rejects incomplete, mixed-threshold/model/seed, unknown identity, class, language/corpus or pairing mismatches. A small-group status accompanies descriptive estimates; it never returns a fabricated zero for unavailable cells. Hand-calculated unequal-cluster fixtures validate the weighting.

For the inspected tiny release, the best fixed pair has three common sources and the English source speaker pool is four. A broader sparse incomplete-block design would change the estimand and require fresh positivity/identifiability review; it was not silently substituted into the requested fixed-factor analysis. Full [MLAAD author release](https://huggingface.co/datasets/mueller91/MLAAD/tree/main) is gated and requires acceptance/sharing of account information. No authentication/consent restriction was bypassed. Authorized full metadata could enable a different development design, but unused records from the same speakers do not create independent confirmation.
