# Phase 4 C1 novelty decision

Recommendation: **B — SUPPORTING VALIDATION CONTRIBUTION**, with **C — ENGINEERING INFRASTRUCTURE** as its reproducible artifact. C1 is currently **not** a justified primary international scientific novelty. The source-matched generator/order hypothesis remains untested, rather than disproved by a null matched experiment.

| Candidate claim | Nearest work / overlap | Actual new LAVA evidence | Remaining uncertainty / classification |
|---|---|---|---|
| Sequential media robustness | [RADAR overview](https://arxiv.org/html/2605.09568v3) already constructs sequential media processing | Explicit reproducible order reversal and classwise diagnostic for existing artifacts | New protocol application alone is insufficient novelty |
| Source-controlled generator/order interaction | MLAAD source tracing and established paired/interaction methods; no definitive matching order study identified in this bounded search | Sparse overlap quantified; no adequate fixed-pair matched experiment executed | NOT_ESTABLISHED; absence in a search is not novelty clearance |
| Silence/level deconfounding | [ASVspoof 5](https://arxiv.org/html/2502.08857v1), §4.2, already reduces level/duration/non-speech shortcuts | Same-record edge/amplitude sensitivity, exact observed-window diagnostics | VALIDATION; not first discovery of silence shortcuts |
| Leading silence as a cue | [CVPR 2025 Circumventing Shortcuts](https://openaccess.thecvf.com/content/CVPR2025/html/Smeu_Circumventing_Shortcuts_in_Audio-visual_Deepfake_Detection_Datasets_with_Unsupervised_Learning_CVPR_2025_paper.html) demonstrates and controls leading-silence bias | Changes in actual artifact decisions under a conservative diagnostic | Task/data differ; still no proof the LAVA models exploit silence causally |
| Class-asymmetric codec/noise failures | FP-NAC and fixed-threshold noise work already examine class-specific failure; see NEAREST_PRIOR_ART.md | Both artifact classes and ranking retained; large nuisance sensitivity disclosed | Supporting evidence; no new generic mechanism |
| Gain invariance of the implementation | Standard floor/reference signal-processing behavior | Model-free exact replica and scaled-floor counterfactual localize feature non-invariance | ENGINEERING DIAGNOSIS; no altered-preprocessor detector improvement or independent confirmation |

Current evidence cannot fill the journal's three-primary-contribution objective by renaming infrastructure, an estimator application and a small sensitivity run as separate international novelties. Full C1 scaling is not justified until a content-supported and independently grouped design is feasible.

The strongest evidence-grounded next direction is controlled learning/evaluation that separates source-content, preprocessing-floor/segment-boundary effects and class-error direction. Any C2 mechanism must beat standard same-view augmentation, standard KD and paired consistency with controlled data and fair resources. PCL-NET and DK-CAST remain direct overlap checks. A teacher-free alternative could be considered if better justified, but no novel objective or training result is established here.

This review covered current primary RADAR, shortcut and ASVspoof sources alongside the prior Phase 3 comparisons. It did not establish that no earlier paper contains a source-controlled order interaction. Replication remains absent; meaningful teacher quality and training provenance remain pending. C3 remains deferred rather than used as an unsupported third contribution.
